# Security

The CLI and registry validator are an early v0.1 foundation; no long-term supported release is declared. Report ordinary reproducible bugs through the bug form. Remove tokens, personal data, and private paths from logs.

For suspected vulnerabilities, use GitHub's private vulnerability reporting feature **if it is enabled**. A dedicated private security contact has not yet been designated; do not post credentials or sensitive exploit details in public issues. The owner must establish a private reporting route before broader deployment.

Registered projects maintain their own security policies and reporting channels. Do not report a third-party project's vulnerability to a public community thread.
