# CONNECT-SBG history and C.O.N.N.E.C.T. EAGLE foundation

This repository preserves the original CONNECT-SBG drought-analysis notebooks, report and environment snapshot.

The new **C.O.N.N.E.C.T. EAGLE** Git foundation is staged in [`connect-eagle-foundation/`](connect-eagle-foundation/README.md): a Python CLI, project registry, five templates and community documentation. Projects can join the future registry while keeping their existing repositories and ownership.

Start with the [CLI quickstart](connect-eagle-foundation/connect-eagle-cli/README.md), [migration audit](connect-eagle-foundation/AUDIT_AND_MIGRATION.md) or [engineering handoff](connect-eagle-foundation/NEXT_STEPS.md).

Historical files at this repository's root retain their existing history and licensing status. The MIT licenses in new component directories cover those components only.
