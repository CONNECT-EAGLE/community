# Project lifecycle

| Status | Meaning | Contributor expectation |
| --- | --- | --- |
| Active | A maintainer confirms ongoing work and a usable contribution route | Follow current issues and review guidance |
| Incubating | Scope or community practices are still being established | Help shape a small, explicit deliverable |
| Experimental | An exploratory method or prototype without validated general use | Expect changes; check stated limitations |
| Maintenance | Stability and fixes are prioritized | Coordinate larger features first |
| Completed | The planned deliverable is finished | Check whether follow-up work is welcome |
| Archived | Retained for reference; new work is not expected | Cite the historical state and contact owners before revival |

The registry v1 vocabulary remains `planning`, `active`, `maintenance`, `completed`, `archived`. The directory displays these exact values for registered projects. Describe incubation or experimental limitations in the project's README/description; do not put unsupported status values into schema v1. Infrastructure may use Incubating separately because it is not a registered scientific project.

Maintainers should update status when their capacity or scope changes and review it before promoting a project. Silence alone is not proof that a project is abandoned. The historical CONNECT-SBG material is labeled historical/maintenance unknown, rather than claiming its owners have archived it.
