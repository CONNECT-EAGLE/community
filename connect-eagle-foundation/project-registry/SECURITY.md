# Security policy

Report suspected vulnerabilities privately through GitHub's **Report a vulnerability** feature if enabled, or a privately reachable repository maintainer. Do not publish credentials, sensitive data or exploitation details in issues.

For v0.1, maintainers support the newest patch release only. The CLI does not store tokens: GitHub CLI owns authentication. Update Git, Python and dependencies through their normal channels.

Before launch, configure private vulnerability reporting and a monitored security contact. No response-time service commitment is implied by this early community project.
