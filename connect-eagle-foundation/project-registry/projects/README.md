# Registered projects

One `<project-slug>.yml` file per participating repository. This directory starts empty intentionally: examples and dogfood records are not memberships.

To register, use `connect-eagle submit --registry CONNECT-EAGLE/community --issue` to request review, or open a hub PR adding a schema-v1 record in this directory. Repository ownership stays with the original maintainer. A registry maintainer reviews the request before merging.
