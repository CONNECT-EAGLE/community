# Contributing

You can participate from your own repository. No organization membership or repository transfer is required.

1. Explain the project in a README and choose its license.
2. Install the CLI and run `connect-eagle init` at any location inside the Git working tree.
3. Review the generated metadata and run `connect-eagle doctor`.
4. Run `connect-eagle submit` to prepare the record, then use `--registry OWNER/project-registry --push` when the registry is live.
5. Respond to the registry review. Start with a documentation fix, reproducible example, issue triage or a clearly scoped scientific question.

Use feature branches and small, descriptive commits. In a PR explain the problem, what changes, and how you checked it. Cite datasets and methods. Do not commit secrets, large data downloads, generated notebook outputs, or material you cannot redistribute. Link to versioned dataset landing pages instead.

A missing citation or license produces guidance; it does not disqualify a newcomer. Registration never grants reuse rights. Newcomers can ask for help through a repository issue without installing the CLI.
