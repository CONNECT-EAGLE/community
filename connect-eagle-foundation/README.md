# C.O.N.N.E.C.T. EAGLE — Git foundation

**Collaborative Nexus for Networking, Education, and Career Training Supporting EAGLE VSWIR and TIR.**

GitHub is infrastructure for this community. Projects keep their existing owners and repositories; a small metadata file connects them to a curated registry.

This foundation is staged as separable repository directories while preserving the historical CONNECT-SBG repository. Start in `connect-eagle-cli/README.md` for installation and `NEXT_STEPS.md` for the engineering handoff.

| Directory | Intended repository | Responsibility |
| --- | --- | --- |
| `connect-eagle-cli` | `connect-eagle-cli` | Python/Typer CLI and canonical schema v1 |
| `project-registry` | `project-registry` | Validated project records and JSON catalog |
| `templates` | `templates` | Five practical starter templates |
| `community` | `community` | Mission, governance, lifecycle and contribution guidance |
| `org-profile` | `.github` | Organization profile and default community health files |
| `website` | `website` | Scope placeholder only |

This is an independent community initiative. It does not claim to be NASA's official EAGLE organization.
