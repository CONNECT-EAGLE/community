# CONNECT EAGLE project templates

Choose `research`, `scientific-software`, `dataset`, `tutorial`, or `working-group`. Copy its contents to a new repository or selectively adapt them into an existing project. Never overwrite existing files blindly.

Template metadata and citation files end in `.example` so they cannot accidentally be submitted as real projects. Run `connect-eagle init` to produce actual `.connect-eagle.yml`, and adapt `CITATION.cff.example` when the work is citable.

The MIT license at this template repository's root covers the template text. It does **not** automatically license a project made from it. Each starter includes license-selection guidance; the project owner must add the actual license and set metadata consistently. Starter directories contain no empty source/test folders or pretend CI jobs.
